# 探迹关税

可添加到手机主屏幕的中文网页应用（PWA）。第一版查询范围为中国原产商品进口美国，使用完整的 USITC 官方 HTS 税则快照，不使用演示税率。

## 手机使用

1. 用手机打开提供的 HTTPS 试用网址，或扫描二维码。
2. iPhone 使用 Safari 的「分享」→「添加到主屏幕」；若出现「作为网页 App 打开」，保持开启，然后点「添加」。安卓使用浏览器的「安装应用」或「添加到主屏幕」。微信里先选择「在浏览器中打开」。
3. 添加后首次打开 App，请保持联网，等页面底部出现「离线基础税则已保存」。之后可以离线查基础税率；全量数据压缩传输约数 MB，实际以网络为准。

试用网址由本机服务提供，电脑关闭、断网或临时隧道停止后，在线查询与更新会停止；已经下载到手机的基础税则仍可离线查询。浏览器清理网站数据后需重新下载。正式长期使用请部署到自己的固定 HTTPS 网址。

已保存应用启动时直接读取本地首页。在线入口故障会回退到已保存的基础税则；连续查询短时间内不反复等待失效入口。离线下载失败会显示明确提示，可联网刷新重试。

## 第一版已实现

- HS 前缀、完整美国 HTS 编码、英文商品关键词和常见中文品类检索。
- 官方英文商品描述、分类层级、基础税率、优惠税率、计量单位和税则脚注。
- Chapter 99 候选条款、官方原文链接与核验提示。
- 经人工核对的完整税号情形单独显示参考合计、税率构成、适用条件及核对日期；目前覆盖 7308.90.30.00 的中国原产一般情形。
- 手机本地收藏、历史记录、收藏时的日期与版本。
- 全量基础税则离线下载；在线查询过的详情也可读取离线缓存。
- 自动检查数据更新：服务运行时每 6 小时检查一次，数据获取超过 24 小时才尝试重新下载；失败继续使用原快照，页面始终显示数据获取日期。

当前随包快照：**2026 HTS Revision 23**，官方发布日期 **2026-11-10**，获取日期 **2026-11-23**；完整原始税则 35,805 行，可查询细分税号 20,422 条。

## 税率与覆盖范围

- 六位 HS 是检索入口，不代表已确认美国八位或十位商品归类；详情需要选择真实存在的细分税号。
- General 是基础税率，Free 显示为「基础 0%，不含加征」，不能据此判断综合免税。复合税率和从量税保留原文，不强行转成百分比。
- 中文名称为常用品类导航参考，完整商品归类以英文官方描述为依据。
- 已核对情形由 `data/reviewed-duty-rules.json` 列明。目前 7308.90.30.00 在中国原产、无适用优惠或排除的一般情形下，参考合计为基础 0% + Section 232 50% + Section 301 25% = 75%，不包含反倾销、反补贴及费用。详情提供完整条件与官方依据。税则快照版本或获取日期变化后须重新核对，未核对税号显示「综合税率待核验」。
- Chapter 99 候选条款仍是宽松筛查线索，可能包含历史条款、只按原产地匹配的条款、豁免条件或其他不适用条款。**不对候选条款自动求和，不计算最终应缴税率。**仅适用于其他税率栏的脚注不用于中国原产 General 栏候选筛查，原始脚注保留供查看。上游历史状态标记不是官方实时政策判定。
- 反倾销、反补贴和准入认证未接完整数据库，一律标记待核验，并提供官方入口；未知不会显示为「无」。
- 本地服务的离线基础税则保留已核对情形的日期与条件；未缓存过的完整商品详情仍提示联网核验附加税。GitHub Pages 版保存整份快照和核对规则后可在手机离线读取。
- 本版提供当前下载快照查询，不提供历史日期税率回溯，也不包含报关单生成、运费或进口税费报价。

## 在电脑启动

需要 Node.js 20 或更高版本，无需安装第三方运行依赖。仓库以 `data/hts-full.json.gz` 保存完整官方快照；首次运行会解压并校验，再生成离线基础税则。已有原始 JSON 会保留，不用压缩快照覆盖更新的数据。解压或克隆后在本目录运行：

```sh
npm start
```

然后打开 `http://localhost:8787`。同一 Wi-Fi 的手机可以用电脑的局域网 IP 和 8787 端口进行浏览器预览；正式 PWA 安装、服务工作线程和离线功能需要 HTTPS（localhost 开发环境除外）。

Mac 可双击 `启动探迹关税.command`。服务器文件只公开 `public/` 目录，`data/`、源码与运行目录不会公开下载。收藏和历史保存在使用者自己的浏览器，不上传服务器。

手动更新数据：

```sh
node scripts/update-data.mjs
```

数据下载、章节完整性与官方版本校验全部成功后才替换快照；失败保留或恢复旧数据。运行中的独立服务会在重启后读取命令行更新的数据；服务内的自动更新会即时刷新查询内存。

测试：

```sh
npm test
```

直接调用底层脚本前，可先运行 `node scripts/prepare-data.mjs`。GitHub Actions 和静态构建脚本会自动准备数据。原始 JSON、生成的离线 JSON 和 `dist/` 不提交仓库；更新仓库随附快照时，应重新生成 `data/hts-full.json.gz` 并校验解压字节与原数据一致。

## 固定网址部署

手机独立使用优先采用 GitHub Pages 静态版，无需本机服务器或 API Key。它在手机浏览器执行原有的税则检索和候选税筛查，保留来源日期及待核验提示。构建命令与自动发布说明见 [GITHUB_PAGES.md](GITHUB_PAGES.md)。网站发布后，手机无需电脑开机即可联网访问；保存数据后可离线查询。静态版数据更新需重新发布，不能视为实时税率。

目录也提供 Dockerfile，可在支持 Node 或 Docker 的服务器部署原完整服务；托管费用由所选平台和方案决定。

- 默认端口 8787，支持 `PORT`、`HOST` 环境变量。
- 健康检查路径 `/health`。
- 官方税则文件随包提供，首次启动不依赖下载成功；更新任务需要能访问 `hts.usitc.gov` 和 `usitc.gov`。
- 长期部署后应使用固定 HTTPS 域名，并设置运营所需的数据核验与维护流程。
- 免费云服务的休眠或文件持久性取决于提供商，不应把临时试用隧道当作生产部署。
